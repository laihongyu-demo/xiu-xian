## 1. 基础属性

> 原文注明：各属性的**名称待定**，下表为实际效果。

| 属性 | 实际效果 |
| --- | --- |
| 攻击 | 造成伤害 |
| 防御 | 抵御攻击 |
| 速度 | 决定先手；大于敌方则先手出击；达到敌方 2 倍及以上可触发连击（额外 1 次攻击） |
| 闪避 | 躲避攻击 |
| 气血 | 生命值，战斗中归零判定为失败 |
| 暴击 | 暴击概率；伤害倍率暂定 1.5 倍；概率有硬上限，**永远不会达到 100%**，具体上限待定 |

## 2. 特殊属性

特殊攻击 / 特殊防御是**一组系列属性**，按仙、魔、鬼、妖、佛五系各配一套攻防：

| 属性 | 效果 |
| --- | --- |
| 特殊攻击（仙／魔／鬼／妖／佛） | 无视普通防御；**只对「特防不是本系」的目标产生效果** |
| 特殊防御（仙／魔／鬼／妖／佛） | 无视普通攻击；**只能抵御本系的特殊攻击** |
| 雷击抗性 | 微量增加渡劫概率，总增幅不超过约 10%，避免过于夸张 |

### 特攻特防的配对规则

记 `攻X` / `防X` 为 X 系的特殊攻击 / 特殊防御（X ∈ 仙、魔、鬼、妖、佛）：

- `防X` 只能抵御 `攻X`；
- 反过来，`攻X` 对「带 `防X` 的目标」无效，对其它目标生效。

> 由此推导出：**同系之间特殊攻击无效**（仙攻打仙防 = 无效）。这是按原文「攻击只能对非对应的产生」的字面理解，若你的本意是同系才生效，需要调整方向。

### 与基础属性的关系

- 特殊攻击无视**普通防御**，只能被对应的**特殊防御**抵消。
- 基础攻击则相反：由普通防御抵御，不受特防影响。

## 4. 伤害公式

原文给出的核心公式：

```
最终伤害 = [(攻击 + buff增伤) - 伤害减免 - 敌方防御] + (真攻 - 真防)
```

- 若**未破防**，则伤害为 1。
- 「真攻 / 真防」与属性表中的「特殊攻击 / 特殊防御」是**同一概念**（A15 已定），即五系特殊攻防；正式名称尚未定稿，后续统一用词即可。

### buff 增伤

- 灼烧伤害 = （原文留空）
- 灼烧在「特殊效果」表中的描述为：持续流失气血，火系伤害 +50%，持续 X 回合。

### 减抗 / 破甲

```
破甲 = 敌方防御 - (敌方防御 × X%)
```

示例：`100 - (100 × 10%) = 90`

> `X%`、`伤害减免` 的来源与叠加上限均未定义。

## 6. 战斗日志呈现样例

`公式逻辑.md` 给出的日志格式（含伤害构成拆分）：

```
**魔帝** 登场...
**无名修士** 登场...
[回合一] **魔帝** 对 无名修士 造成 1 伤害
[回合一] **无名修士** 使用<魔炎剑>发动暴击对 **魔帝** 造成**1,000,000**伤害[<基础攻击500,000><灼烧200,000><魔攻300,000>]
[回合一] **无名修士** 的 **九幽魔龙** 发动暴击对 **魔帝** 造成**200,000**伤害
**魔帝** 败退
战斗结束
```

可提炼的呈现规则：

- 加粗角色名与最终伤害数值
- 伤害后以 `[...]` 拆分来源构成
- 暴击、技能名（`<...>`）、召唤物（九幽魔龙）单独标注
- 1 点伤害即「未破防」的表现
