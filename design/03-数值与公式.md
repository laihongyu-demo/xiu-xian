# 03　数值与公式

> 来源：`docs/设计文档.md` §数值类型设计；`docs/公式逻辑.md`；`docs/数值设定.xlsx` →「单位」。

## 1. 基础属性

> 原文注明：各属性的**名称待定**，下表为实际效果。

| 属性 | 实际效果 |
| --- | --- |
| 攻击 | 造成伤害 |
| 防御 | 抵御攻击 |
| 速度 | 决定先手；大于敌方则先手出击；达到敌方 2 倍及以上可触发连击（额外 1 次攻击） |
| 闪避 | 躲避攻击 |
| 气血 | 生命值，战斗中归零判定为失败 |
| 暴击 | 暴击概率；伤害倍率暂定 1.5 倍；概率有硬上限，**永远不会达到 100%**，具体上限待定 |

## 2. 特殊属性

特殊攻击 / 特殊防御是**一组系列属性**，按仙、魔、鬼、妖、佛五系各配一套攻防：

| 属性 | 效果 |
| --- | --- |
| 特殊攻击（仙／魔／鬼／妖／佛） | 无视普通防御；**只能被同系的特殊防御抵御** |
| 特殊防御（仙／魔／鬼／妖／佛） | **只能抵御同系的特殊攻击**；对普通攻击无效 |
| 雷击抗性 | 微量增加渡劫概率，总增幅不超过约 10%，避免过于夸张 |

### 配对规则（以仙系为例）

- **仙攻 → 只有仙防能挡。** 其他四系的特防、以及普通防御都无法抵消，目标直接受到伤害。
- **仙防 → 只挡仙攻。** 既不能抵御其他四系的特攻，也不能抵御普通攻击。

通则（X ∈ 仙、魔、鬼、妖、佛）：

- `攻X` 只被 `防X` 抵消，其余防御一律穿透。
- `防X` 只抵消 `攻X`。
- 是否被挡，只看「攻击的系别」与「目标的特防系别」是否**相同**。

> 推论：同系对战时若对方带了本系特防，特攻会被吃掉；跨系对战则特攻必定生效。因此「带哪一系特防」本身就是一个取舍，而不是简单的数值堆叠。

### 与基础属性的关系

- **普通攻击 ↔ 普通防御**：普通攻击由普通防御抵御，特防完全不管。
- **特殊攻击 ↔ 对应特殊防御**：特攻由同系特防抵御，普通防御完全不管。
- 两者是两条互不干扰的伤害线。

> 设计意图：特殊属性主要用来**支撑流派玩法**（不同流派走不同系的特攻／特防），而不是单纯堆数值。

## 3. 取整规则

- **所有局内数值一律舍去小数**（向下截断，不四舍五入）。
- 适用范围包括伤害、修为、气血、概率以外的所有整数型展示与结算。

> 附带结论：境界表里那些多位小数的「所需修为」，在游戏内一律按整数处理。

- 所有增/减益**仅在战斗中产生和生效**。

## 5. 伤害公式

核心公式：

```
最终伤害 = [(攻击 + buff增伤) - 伤害减免 - 敌方防御] + (真攻 - 真防)
```

- 若**未破防**，则伤害为 1。
- 「真攻 / 真防」与属性表中的「特殊攻击 / 特殊防御」是**同一概念**（A15 已定），即五系特殊攻防；正式名称尚未定稿，后续统一用词即可。

### 终伤

- **终伤** = 计算完所有基础数值与 buff／debuff 之后的最终伤害。
- 终伤**按单回合结算**。之所以限定「单回合」，是因为存在多回合生效的 buff／debuff，每回合都要重新算一次。

### 破甲（已更正）

原「按百分比削减敌方防御」的写法作废，改为**破防触发额外伤害**：

- 当自身攻击 **>** 敌方防御 × 阈值比例（例如 1.5 倍）时，触发破甲，产生额外伤害。
- 阈值比例与额外伤害的量级**待定**。

### 伤害减免

伤害减免是**按比例抵消伤害**，但抵消范围尚未确定，有两种候选口径：

| 口径 | 说明 |
| --- | --- |
| 限定范围 | 只抵消普通攻击，或只抵消特攻，或只抵消 debuff 产生的伤害 |
| 终伤抵消 | 不分来源，直接按比例削减终伤 |

> 选定后需要同步写进公式，否则「伤害减免」在公式里的位置（是否先于特攻结算）会产生歧义。

## 7. 战斗日志呈现样例

`公式逻辑.md` 给出的日志格式（含伤害构成拆分）：

```
**魔帝** 登场...
**无名修士** 登场...
[回合一] **魔帝** 对 无名修士 造成 1 伤害
[回合一] **无名修士** 使用<魔炎剑>发动暴击对 **魔帝** 造成**1,000,000**伤害[<基础攻击500,000><灼烧200,000><魔攻300,000>]
[回合一] **无名修士** 的 **九幽魔龙** 发动暴击对 **魔帝** 造成**200,000**伤害
**魔帝** 败退
战斗结束
```

可提炼的呈现规则：

- 加粗角色名与最终伤害数值
- 伤害后以 `[...]` 拆分来源构成
- 暴击、技能名（`<...>`）、召唤物（九幽魔龙）单独标注
- 1 点伤害即「未破防」的表现
