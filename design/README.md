# design　整理后的设计设定

本目录是从 [`docs/`](../docs/) 的原始随笔中提取、归类后形成的结构化设定，供后续设计与开发直接引用。

## 整理原则

1. **只搬运，不发挥**：内容全部来自 `docs/` 原文，不补充原文没有的设计、数值或玩法。
2. **保留原样地记录问题**：原文自相矛盾、前后不一致、只写了一半的地方，不擅自裁定，统一登记在 [99-待定与冲突清单.md](99-待定与冲突清单.md)。
3. **数值表以 xlsx 为准**：长表格（境界等级、装备库、材料库等）仍保留在 `docs/*.xlsx`，本目录只写规则、口径与关键样例，避免两份数据各自漂移。
4. **原始文件不动**：`docs/` 下的文件保持原样，作为存档；后续修订只在本目录进行。

## 建议阅读顺序

先读 `02`（境界骨架）→ `03`（数值口径）→ `04`（战斗）→ `06`（物品），这四份构成可玩循环的最小闭环；区域与纪元背景可以后置。

> 原有的 `01-世界观.md` 已删除：世界观内容按「空间 → 07、时间 → 08、种族 → 02、题材 → 10」拆入各系统文档；小说向的主角设定不进游戏，原文与决策记录见 [99-待定与冲突清单.md](99-待定与冲突清单.md) §D。

## 与 docs/ 的关系

```
docs/          原始随笔与数值表，存档，不再修改
design/        提取后的结构化设定，后续在这里修订
design/data/   工作用数值表，可编辑
```

两份内容出现分歧时，以 `design/` 为准，并回填到 99 清单记录决策。
