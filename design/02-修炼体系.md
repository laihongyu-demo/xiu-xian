> 来源：`docs/设计文档.md` §修炼系统；`docs/数值设定.xlsx` 的「境界等级」「晋升劫灾」「Sheet6」。

## 1. 境界结构

- 分为**大境界**和**小境界**。
  - 大境界 = 境界分组，例如炼气期、渡劫期。
  - 小境界 = 最小等级单位。开发中可直接理解为「x 级」，例如炼气一层、渡劫一层。
- 境界等级表（`数值设定.xlsx` →「境界等级」）的字段含义：

| 列 | 含义 |
| --- | --- |
| 等级 | 全局等级序号，0 为凡人 |
| 境界分组 | 凡境 / 仙境 / 混元 / 不朽 / 混沌 / 鸿蒙 / 道 |
| 境界 | 大境界名 |
| 小境界 | 大境界内的层级名 |
| 突破方式 | 如「修为」「修为+凝聚根基」「渡劫」 |
| 递增 | 升级所需修为的复利系数 |
| 下一级所需修为 | 进入下一级所需的修为值 |
| 渡劫 | 是否需要在突破时渡劫 |

### 修为需求递推规则

表内数值满足：**本级所需修为 = 上一级所需修为 ×（1 + 该级递增）**。

- 凡人 → 炼气一层：10,000 作为起始基准
- 每进入新的大境界，递增系数整体换档（0.5 → 0.2 → 0.25 → 0.3 → 0.35 …）
- 「道」分段是唯一一处逐级翻倍的区间

## 3. 突破与渡劫

### 突破规则
- 突破境界需**消耗一定修为**。
- **渡劫节点（A3／A4 已定）**：只在「每个大境界的最后一个小境界 → 下一个大境界」时渡劫。
  - 凡境：炼气九层、筑基九层 …… 大乘九层的下一次突破，都需要渡劫。
  - 仙境与混元：前期 → 中期 → 后期只消耗修为，圆满突破到下一境界时才渡劫。
  - 本身只有一个层级的大境界（至高大帝、至高大主宰、不朽、混沌、鸿蒙），每一级就是一个渡劫节点。
- 原「后期每个境界都需要渡劫（从哪个阶段开始待定）」已被 A3 取代，不再适用。
- **渡劫期是例外**：该境界每突破一个小境界都要渡劫（雷灾 → 火灾 → 风灾 → 肉身衰 → 气运衰 → 神识衰 → 道心衰 → 因果衰 → 天人五衰），不适用「仅圆满渡劫」（§2 脚注 ※2）。
- 圣人九转暂仍按原表「每转渡劫」，待 A16 确认（§2 脚注 ※3）。

### 渡劫是什么

- 渡劫是突破时的一次**强制考验**：消耗修为进入渡劫，成功才能进入下一境界。
- 形式因境界／劫灾而异：常见为**雷劫**，也有其它形式（如渡劫期的天人五衰、火灾、风灾）。
- 天劫有**强度**概念，玩家可以选择「硬抗」或「削弱」。

### 两种应对策略

| 策略 | 做法 | 成功率 | 属性增幅 | 失败代价 |
| --- | --- | --- | --- | --- |
| 硬抗 | 不借助任何外力，**不使用任何道具** | **概率极低** | **1.x 倍**（高于基准），肉身强度大幅提升 | 掉落的修为**更多** |
| 道具削弱 | 用丹药、阵法、对应天劫的特化道具衰减天劫强度 | 高（最稳健） | **1 倍**（基准），数值正常提升 | 常规扣修为 |

- **两条路线互斥**：一旦选择硬抗，丹药、阵法、特化道具等**任何道具类加成一律不可使用**；用了道具就属于道具削弱路线，拿不到 1.x 增幅。
- 这样硬抗才是真正的「裸拼」：高风险的代价不会被道具抹平，高收益也只在承担风险时才能拿到。
- **道具削弱**可叠加多种手段：丹药 + 阵法 + 对应天劫的特化道具。
- **阵法**属于道具侧：可使用不同类型阵法，并可在**阵眼布置法宝**。
- 原文的「直接渡劫 / 服用丹药渡劫 / 阵法渡劫」三分法，收敛为「硬抗」与「道具削弱」两类：前者对应直接渡劫，后者对应丹药与阵法。
- 增幅基准记为 1，硬抗为 1.x；**x 的取值与上限待定**。
- 「雷击抗性」是自身属性而非道具，硬抗时是否仍计入成功率加成，待确认。

### 天劫强度与衰减

- 天劫强度是一个可被道具削减的数值，削弱后判定难度下降、渡劫概率上升。
- **特化道具**针对特定天劫，效果强于通用丹药／阵法（例：雷劫对应避雷／雷抗类道具）。
- 特殊属性「雷击抗性」额外提供渡劫概率加成，增幅不超过约 10%（见 [03-数值与公式.md](03-数值与公式.md) §2）。

### 成功与失败

- **成功**：进入下一境界，并按所用策略发放属性增幅（硬抗 1.x、道具 1）。
- **失败**：损失修为，境界不进阶；硬抗的损失**大于**道具削弱。
- 渡劫成功率的计算公式、失败是否附带降级／受伤／道基受损，均待定。
- 成功率上限 100%，达到上限后不可再叠加提高。

## 4. 修为获取

### 时间估算口径

取一定时间段内（具体范围待定）的**每 5 秒均值**，计算到达下一境界所需时间，精确到分。

### 自动获取

- **开启条件**：晋升到炼气期一层（等级 1）时，系统**赠送《先天吐纳法》并自动激活**，随即开启自动修炼。赠送、激活、开自动是同一时点，不存在「有功法但没激活」的中间状态。
- 每 5 秒获取一次修为，每次数值在 `min ~ max` 范围内随机。
- **与手动点击共用同一 `min ~ max` 区间**，两者只是触发方式不同，单次收益范围一致。
- `min / max` 受功法神通、服用丹药、突破境界等方式提升。
- **无法关闭**：原按钮替换为 label，文案为
  > 气随诀转，嘘呵呼呬吹唏六字轮转，周天自运不息
- 每轮自动运行结束：渐出标签展示所增加的修为值。

### 手动点击（仅凡人阶段）

- **适用范围**：只有等级 0「凡人」阶段需要通过手动点击获取修为。
- **切换点**：晋升到炼气期一层（等级 1）后，赠送并自动激活《先天吐纳法》，永久转为自动获取，不再出现手动按钮。
- 结算区间与自动获取相同（同一 `min ~ max`）。
- 每次点击持续 5 秒。
- 按钮文案：点击前「吐纳调息」→ 点击后「调息中」→ 完成后恢复「吐纳调息」。
- 结束后提示文本：
  > 一缕微不可查的灵气沉入丹田

### 其他方式

| 方式 | 作用 |
| --- | --- |
| 丹药 | **直接增加修为**（一次性发放） |
| 阵法 | 提升修为**获取效率**（作用于 `min ~ max` 区间） |
| 功法 | 提升修为**获取效率** |

> 效率类提升最终体现为 `min ~ max` 的上移，不直接发放修为。具体加成曲线未定。
