# 07　区域与地图

> 来源：`docs/设计文档.md` §区域设计；`docs/地域.md`。

## 1. 世界尺度与地图类型

> 本节由原 `01-世界观.md` 拆入，并按游戏的地图／区域视角改写。

### 世界层级

原文把世界定义为「一个宇宙」，层级为：

```
主宇宙 → 子宇宙 → 星域 → 星系 → 旋臂 → 星球（恒星、行星）
```

现有区域设计（凡间、三界、神界）大致处于「星球 ～ 星域」这一量级，尚未与上述层级正式对齐。

### 地图类型

原文的「星球类型」在游戏中按**地图功能**理解：

| 类型 | 原文定义 | 游戏内定位（建议） |
| --- | --- | --- |
| 聚居类 | 以生物聚居为主 | 城镇、坊市，交易与情报集中地 |
| 生产类 | 以资源产出和加工为主 | 材料采集点，与洞府产出、炼器炼丹衔接 |
| 秘境类 | — | 副本／秘境入口 |

> 「游戏内定位」一列为整理时的建议映射，原文未作此表述。

### 阴阳两面

一个星球分阴阳两面：阳间、阴间。

- 游戏中可作为两套并行地图：阳间为主活动区，阴间对应冥府、亡魂相关的区域。
- 阴阳两面的对应关系、是否互通，均未定义。

## 2. 总体结构

区域分为**主世界**与**秘境**，大体分为五个部分。

### 主线流程

```
凡间飞升 → 登仙台 → 仙鬼魔三界 → 神界之门 → 神界 → 混沌 → 混沌长河尽头 → 鸿蒙
```

### 维度划分（来自 `地域.md`）

- 每个地图相当于不同维度的世界。
- 仙、鬼、魔属于**同一维度**。
