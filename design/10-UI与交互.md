# 10　UI 与交互

> 来源：`docs/设计文档.md` 开篇定位、§UI设计、§修炼系统；`docs/公式逻辑.md`。

## 1. 游戏定位

- 题材：玄幻、修仙、神话；故事基调为**爽文**。
- 极简**纯文字 UI**。
- 主要内容：数值养成 + 离线挂机 + 回合制战斗。
- 纯单机，暂定**无主线 / 剧情**，可加入少量碎片化文本，供玩家自由脑补。
- 自由养成发展 PVE。

## 2. UI 设计

- 初版暂时使用默认 UI，但需要**预留占位**，方便后续直接替换素材。
- 后续可能使用 Aseprite 设计像素 UI。

## 3. 设计文档的三段划分

原文把设定分为三部分：

1. 文本设定
2. 框架设定
3. 技术设定

> 目前只有前两类有内容，技术设定尚未撰写。

## 4. 交互文案清单

以下文案为原文明确给出的，建议作为 UI 常量集中管理。

| 场景 | 文案 |
| --- | --- |
| 手动修炼按钮（点击前） | 吐纳调息 |
| 手动修炼按钮（点击中） | 调息中 |
| 手动修炼结束提示 | 一缕微不可查的灵气沉入丹田 |
| 自动修炼开启后（替换按钮的 label） | 气随诀转，嘘呵呼呬吹唏六字轮转，周天自运不息 |
| 自动修炼每轮结束 | 渐出标签展示本次增加的修为值 |

## 5. 战斗日志格式

```
**魔帝** 登场...
**无名修士** 登场...
[回合一] **魔帝** 对 无名修士 造成 1 伤害
[回合一] **无名修士** 使用<魔炎剑>发动暴击对 **魔帝** 造成**1,000,000**伤害[<基础攻击500,000><灼烧200,000><魔攻300,000>]
[回合一] **无名修士** 的 **九幽魔龙** 发动暴击对 **魔帝** 造成**200,000**伤害
**魔帝** 败退
战斗结束
```

详见 [03-数值与公式.md](03-数值与公式.md) §6。

## 6. 渡劫文本

- 每种劫灾配「劫象」「成功祝语」「失败谶言」三段文本。
- 另有「天道警示谶言」「证道敕言」两类长文本，见 [02-修炼体系.md](02-修炼体系.md) §3 与 `数值设定.xlsx` →「晋升劫灾」。
