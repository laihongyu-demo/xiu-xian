## 3. 装备卡样式

原文给出的展示模板（以「金霞冠」为例）：

```
装备名称：金霞冠
装备品质：仙品
—————————————————————————————————————————————————————————
固定属性：
- 攻击 +10~18
- 防御 +12-20
随机词条：
- 攻击 +11 （8~12）
- 暴击 +5% （3~5）
—————————————————————————————————————————————————————————
套装属性：无
[1件]：无
[3件]：无
[5件]：无
—————————————————————————————————————————————————————————
装备描述：
冠绽金光，蔽形隐迹，神目难察。金光所至，可眩目夺魂，破邪祟于无形
```

要点：

- 属性分**固定属性**（区间）与**随机词条**（实际值 + 可取值范围）。
- 套装按件数（1/3/5）分档。
- 数值区间分隔符原文混用 `~` 与 `-`。

## 7. 装备库与材料库

### 装备库

- 共 84 条，其中仅前 12 条有 id（1001–1012），其余 id 为空。
- 字段：id / 名称 / 类型 / 子类型 / 品质 / 描述。
- 已填品质只有两种：`下品后天灵宝`（天兵制式 7 件）、`法器`（其余入门装备）。
- 大量条目只有名称与类型，品质为空（如诛仙四剑、番天印、混元金斗等）。

### 材料库

- 共 32 条，字段：id / name / type / 品级；id 与**品级全部为空**。
- 类型只有两种：`炼器`、`炼丹`。
- 存在疑似录错：`人参[十年]` 出现两次（第 11、13 行），缺 `人参[千年]`。
- 部分行右侧带备注列，记录了材料的出处（如「先天葫芦藤 → 赤橙黄绿青蓝紫七色葫芦」「五针松 → 金木水火土各 10 枚」）。
