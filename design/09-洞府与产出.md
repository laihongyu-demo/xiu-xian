# 09　洞府与产出

> 来源：`docs/设计文档.md` §其他设计 → 洞府道场。

## 1. 定位

洞府道场是一个**小型的家园养成子系统**，用于辅助主系统（修炼）养成。

## 2. 基础产物

原文写的是「基础产物（）」，括号内为空，即产物分类尚未命名。

| 产物 | 产出建筑 |
| --- | --- |
| 肉 | 灵兽园 |
| 木 | 林场 |
| 草 | 灵药田 |
| 铁 | 矿场 |
| 灵石 | 灵石矿脉 |

## 3. 尚未定义

- 产物与主系统的兑换关系（例如肉、木、草是否用于炼丹或炼器）
- 建筑的等级、升级消耗、产出速率
- 是否支持离线累积（大概率与 §08 离线挂机共用一套结算）
- 是否需要投入人力 / 弟子管理
- 与「储物系统」（须弥芥子 / 乾坤袋 / 山河画卷）的关系
