# 04　战斗系统

> 来源：`docs/设计文档.md` §战斗系统；`docs/公式逻辑.md`；`docs/数值设定.xlsx` →「特殊效果」。

## 1. 基本规则

- 战斗逻辑：**回合制**。
- 胜负：一方气血归零即判负。
- **回合上限 50**：50 回合内未击败防守方，则判负。

### 先手判定

- 对比双方速度值，速度大的一方先手。
- 速度相等时随机判定。
- **连击**：速度 ≥ 敌方 2 倍时触发，连续攻击 2 次。

### 伤害计算

见 [03-数值与公式.md](03-数值与公式.md)：`最终伤害 = [(攻击 + buff增伤) - 伤害减免 - 敌方防御] + (真攻 - 真防)`，未破防时伤害为 1。

## 2. 关卡与挂机

- 关卡闯关参考《剑与远征》这类游戏的冒险模式。
- 界面同样参考该模式，**不设置地图逻辑**，仅展示小人动画。
- 首次战胜 boss 后，解锁**当前关卡**的挂机功能。
- 挂机关卡可自由选择。
- 每个关卡掉落素材均衡，分散于各个关卡。

> 关卡的层数、敌人配置、难度曲线、战力校验方式均未定义。

## 3. 特殊效果

`数值设定.xlsx` →「特殊效果」共 17 条。`X%`／`X回合` 均为待填占位。

| 名称 | 效果 |
| --- | --- |
| 眩晕 | 对敌方造成晕眩效果，敌方无法行动，持续 X 回合 |
| 剧毒 | 对敌方造成中毒效果，持续流失气血，持续 X 回合 |
| 灼烧 | 对敌方造成燃烧效果，持续流失气血，火系伤害 +50%，持续 X 回合 |
| 破甲 | 对敌方每回合抗性减少 X%，持续 X 回合 |
| 流血 | 对敌方每回合气血减少 X%，持续 X 回合 |
| 汲血 | 对敌方造成伤害时概率吸收伤害的 X% 气血 |
| 化劲 | 概率完全反弹伤害 |
| 神行 | 闪避所有伤害，持续 X 回合 |
| 狂骨 | 增加自身攻击 X%，持续 X 回合 |
| 金身 | 增加自身防御 X%，持续 X 回合 |
| 挫锋 | 对敌方每回合攻击减少 X%，持续 X 回合 |
| 反震 | 受击概率反震 X% 伤害，自身仍承伤 |
| 禁锢 | 束缚敌方行动，使其无法行动，持续 X 回合 |
| 蓄势 | 下回合攻击伤害翻倍 |
| 再生 | 恢复 X% 气血 |
| 连击 | 概率进行额外 1 次攻击 |
| 净化 | 清除所有负面状态 |

> 表中所有增减益都只作用于**基础属性**（攻击、防御、速度、闪避、气血、暴击）；特殊攻击与特殊防御**不受任何增减益影响**（见 03 §2）。
>
> 表中的「破甲」是**增益型破甲**（按比例削减防御），与 03 里的「碾压型破甲」（攻击超阈值触发额外伤害）不是同一机制。

### 效果分类（按原文整理）

| 类型 | 条目 |
| --- | --- |
| 控制 | 眩晕、禁锢 |
| 持续伤害 | 剧毒、灼烧、流血 |
| 削弱敌方 | 破甲、挫锋 |
| 自身增益 | 狂骨、金身、神行、蓄势 |
| 恢复/吸血 | 再生、汲血 |
| 反击/反弹 | 化劲、反震 |
| 其他 | 连击、净化 |

> 该分类为整理时的归纳，原文未做此划分。

## 4. 战斗文本

完整样例见 [03-数值与公式.md](03-数值与公式.md) §8。呈现要点：

- 角色登场／败退、回合序号、伤害数值、伤害构成拆分
- 召唤物独立出招（示例中的「九幽魔龙」）
- 暴击与技能名单独标注

## 5. 技能与神通在战斗中的角色

- 技能／神通**多数是局外属性成长**：作用在养成层面，提升攻击、防御等数值。
- 其中**少量**可以产生特殊效果，并带入局内生效。

## 6. 判定与结算细节

| 项 | 规则 |
| --- | --- |
| 出手顺序 | 自身 → 队友 → 召唤物／宠物 |
| 判定层级 | **先判暴击，再判闪避** |
| 状态叠加 | 同名状态采用**叠加回合数**（不刷新时长、不叠层数） |
| 失败惩罚 | 视情况而定，分「有惩罚」与「无惩罚」两种 |
