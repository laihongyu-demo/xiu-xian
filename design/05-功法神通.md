## 1. 功法

### 基本规则

- 功法数量受**技能点**限制；技能点可以增加（见 §4）。
- 功法**不可遗忘**。

### 《先天吐纳法》

不在 Sheet4 清单内，单独说明：

| 项 | 内容 |
| --- | --- |
| 类型 | 修炼类（心法） |
| 获取 | 晋升到炼气期一层时**赠送**，非掉落、非购买 |
| 激活 | 赠送即**自动激活**，无需操作 |
| 效果 | 开启自动修炼，**无法关闭**；界面按钮被替换为固定 label |
| 未定 | 是否随境界提升而增强、是否有升级形态 |

## 2. 神通

原文中「神通」一节只有标题，**没有任何内容**：

- 神通的分类、获取方式、与功法的关系（是否可同时修习、是否占位）均待设计。

## 3. 与修炼系统的关联

- 《先天吐纳法》是自动修炼的开关：晋升炼气时赠送并自动激活，此后每 5 秒自动结算一次修为（见 [02-修炼体系.md](02-修炼体系.md) §4）。
- 功法的 `min / max` 修为区间会影响每次吐纳的收益。

## 4. 学习与生效规则

| 项 | 规则 |
| --- | --- |
| 数量上限 | 由**技能点**限制可学数量；技能点**可以增加** |
| 生效方式 | 只要学会了，**全部同时生效**，不需要在战斗中挑选装备 |
| 效果类型 | 通常提供数值成长；**少量**带局内 buff 效果 |
| 境界限制 | **没有**境界上的使用限制，低阶功法在后期不会失效 |
| 获取限制 | **获取途径按境界开放**：某境界的功法，只有到这个境界才有渠道拿到，避免初期拿到超标功法 |
| 品阶 / 稀有度 | 存在，但具体划分**待定** |
