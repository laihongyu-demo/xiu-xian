## 1. 功法

### 基本规则

- 功法**学习无上限**。
- 功法**不可遗忘**。

### 类型

| 类型 | 定位 |
| --- | --- |
| 术法 | 攻击类 |
| 玄功 | 防御类 |
| 遁术 | 速度类 |
| 身法 | 闪避类 |

| 心法 | 修炼类 |

## 2. 神通

原文中「神通」一节只有标题，**没有任何内容**：

- 神通的分类、获取方式、与功法的关系（是否可同时修习、是否占位）均待设计。

## 3. 与修炼系统的关联

- 《先天吐纳法》属于修炼类功法：学习后自动修炼开启且无法关闭（见 [02-修炼体系.md](02-修炼体系.md) §4）。
- 功法的 `min / max` 修为区间会影响每次吐纳的收益。

## 4. 尚未定义

- 功法是否有品阶 / 稀有度
- 功法数量上限、学习位（若「无上限」指的是可学数量，是否意味着可全部生效？）
- 功法是否提供被动属性加成，还是只提供战斗技能
- 功法与境界的适配限制（低阶功法在后期是否失效）
