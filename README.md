# xiu-xian　文字修仙

单机 Windows 桌面端文字修仙游戏，灵感来源：手游《想不想修真》。

极简纯文字 UI + 数值养成 + 离线挂机 + 回合制战斗，纯单机、自由养成的 PvE 体验。

## 分支模型

采用 `master` + `develop` 双分支开发：

| 分支 | 用途 |
| --- | --- |
| `master` | 稳定分支，保持可运行，仅从 `develop` 合并 |
| `develop` | 日常开发主线，功能开发在此汇总 |
| `feature/*` | 单个功能分支，自 `develop` 切出，完成后合回 `develop` |

提交信息使用中文，动词开头，例如「新增修炼系统自动挂机」。
